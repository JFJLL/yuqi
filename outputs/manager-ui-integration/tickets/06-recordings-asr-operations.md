# Ticket 06：录音、转写与 ASR 运维

## Outcome

管理员可在经理版“录音与转写”页面查询录音、授权播放音频、查看文本与 ASR 状态，并在允许时重试失败任务。

## Blockers

Ticket 01。

## Scope

- 列表筛选、状态、服务商、时长、门店/员工信息和分页。
- 详情中的音频、转写文本、时间信息、错误原因和处理历史。
- 授权音频访问、ASR 主备服务商展示、可重试状态和防重复重试。
- 经理版密集表格、状态标签和详情布局。

## Ownership

独占录音/转写管理页面、ASR 运维 API 增量与测试。系统参数编辑归 Ticket 13；巡检结果归 Ticket 07。

## Acceptance

1. 音频 URL 不可猜测或跨范围访问，过期链接行为明确。
2. 重试有权限、幂等、队列状态与失败反馈。
3. 转写为空、处理中、失败、完成均有明确页面状态。
4. 为 Ticket 07 输出稳定的录音/转写引用契约。

## Evidence

返回接口契约、安全和幂等测试、列表/详情/失败截图、与巡检任务衔接说明。

## Verification

先运行录音授权、ASR 状态、重试和权限定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
