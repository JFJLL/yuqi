# Ticket 16：小程序荐药与培训学习

## Outcome

员工可在原生小程序记录/查看本人荐药业务，领取培训任务、学习课程、继续进度、参加考试并查看结果。

## Blockers

Ticket 02、Ticket 09、Ticket 10。

## Scope

- 荐药记录的本人列表、详情及允许的创建/同步状态展示。
- 学习首页、任务/课程列表、课程详情、章节内容和继续学习。
- 考试、提交、次数/计时反馈、结果与通过状态。
- 进度断点、重复提交、离线/弱网、课程归档或任务过期处理。

## Ownership

独占小程序荐药和培训页面、小程序端状态与测试。后端仅使用 Ticket 09/10 契约；认证基础归 Ticket 02。

## Acceptance

1. 员工只能查看本人任务、进度、成绩和荐药记录。
2. 进度由服务端校验，跨设备恢复合理；客户端不能直接标记完成或通过。
3. 考试刷新、超时、重复提交和次数耗尽行为确定且可理解。
4. 后台能及时看到同一员工的进度和成绩，数据可追溯。

## Evidence

返回页面流程、API 映射、进度/评分/隔离测试、学习与考试关键截图或录屏。

## Verification

先运行小程序契约、进度、考试和安全定向测试，再运行 `rtk pnpm lint`、`rtk pnpm typecheck`、`rtk pnpm test`、`rtk pnpm build` 和项目可用的 `rtk pnpm exec miniprogram-ci` 编译检查；修改后执行 `$code-review`。
