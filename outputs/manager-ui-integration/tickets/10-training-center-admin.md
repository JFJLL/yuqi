# Ticket 10：培训中心数据模型与管理后台

## Outcome

管理员能在经理版“员工业务记录”内管理课程、培训任务、学习进度和考试，并可从巡检问题创建针对性培训。

## Blockers

Ticket 01、Ticket 07、Ticket 09。

## Scope

- 实现 Spec 中课程、章节、任务、进度、试卷、题目、试卷版本和作答实体及迁移、索引、权限和生命周期。
- “学习记录 / 课程管理 / 培训任务与考试”标签页。
- 课程章节编排、草稿/发布/归档、员工/门店任务分配、截止时间。
- 题型/选项/标准答案/分值、发布版本快照、及格分、次数限制、服务端评分、成绩与进度；从问题/规则创建培训任务。
- 历史任务和考试结果在课程后续修改后仍可追溯。

## Ownership

独占培训 schema、API、后台标签页和测试。员工业务记录容器通过 Ticket 09 的扩展点接入；巡检来源只引用 Ticket 07 契约；小程序学习页归 Ticket 16。

## Acceptance

1. 课程发布校验内容完整性，已用课程的破坏性修改受限制或版本化。
2. 任务可分配给员工或门店并解析为可追踪个人进度，重复分配行为明确。
3. 考试次数、计时、评分和通过状态由服务端决定，客户端不能篡改。
4. 管理员能从一条巡检问题建立培训任务并看到后续进度/成绩。

## Evidence

返回 ER/关系说明、迁移与 API、生命周期/权限/评分测试、四个标签页截图及 Ticket 14 契约。

## Verification

先运行迁移、课程生命周期、分配、进度、评分、安全和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
