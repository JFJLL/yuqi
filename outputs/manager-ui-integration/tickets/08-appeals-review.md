# Ticket 08：申诉复核

## Outcome

复核人员在经理版双栏队列中查看巡检、整改和员工申诉的完整上下文，并安全通过或驳回。

## Blockers

Ticket 07。

## Scope

- 左侧待处理/历史队列，右侧上下文、证据、理由和决定区。
- 保留当前更丰富的申诉状态、通知和历史记录。
- 通过、驳回、补充信息等允许的状态与并发保护。
- 空队列、加载、失效任务和无权限状态。

## Ownership

独占申诉管理页面、申诉状态机/API 增量与测试。巡检与整改记录只通过 Ticket 07 契约读取。

## Acceptance

1. 决定前能看到原始录音/文本引用、AI 疑似结果、人工复核、整改与申诉理由。
2. 同一申诉被两人处理时只有一次有效决定，其余获得明确冲突反馈。
3. 决定产生审计与员工可见通知，不泄露后台备注。
4. UI 结构、密度和操作区符合经理版。

## Evidence

返回状态图、并发/权限/通知测试、队列和详情截图、小程序申诉 API 契约。

## Verification

先运行申诉状态机、并发、通知、权限和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
