# Ticket 03：区域、门店与店长

## Outcome

集团管理员可在经理版“区域与门店”页面管理组织树、店长和批量数据，范围管理员只能操作授权区域。

## Blockers

Ticket 01。

## Scope

- 区域与门店列表、筛选、详情、新增、编辑、启停和店长分配。
- 显示员工数、设备数和状态；提供批量导入模板、校验结果与导出。
- 完善当前组织数据模型和范围校验，不迁移经理预览数据。
- 经理版表格、筛选、弹窗和反馈样式。

## Ownership

独占区域/门店/店长数据模型、API、页面和测试。可向 Ticket 01 提交导航注册需求，但不得改共享壳；不得实现员工详情或设备业务。

## Acceptance

1. CRUD、启停、店长分配和批量导入具备成功/部分失败/重复数据反馈。
2. 删除有下属记录的区域或门店时给出安全约束，不产生孤儿数据。
3. UI 与 `06-manager-organization.png` 的区域与门店区域一致。
4. API 与页面同时执行租户和数据范围隔离。

## Evidence

返回 schema/API 契约、导入样例与失败报告、权限测试、页面截图及后续员工/权限 Ticket 可依赖的组织标识契约。

## Verification

先运行迁移、组织 API、权限和导入导出定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
