# Ticket 14：操作审计、接口与同步日志

## Outcome

授权管理员在经理版“操作审计”中追踪管理员操作、接口调用、数据同步和失败记录。

## Blockers

Ticket 01、Ticket 06、Ticket 07、Ticket 09、Ticket 10、Ticket 11、Ticket 13。

## Scope

- 管理员操作、接口、同步、失败记录标签页及筛选、详情。
- 合并当前接口/同步日志入口，保留已有记录与数据范围。
- 敏感信息脱敏、保留周期说明、不可编辑性和导出权限。
- 关键业务决定与配置变更能关联操作人、对象、时间和结果。

## Ownership

独占操作审计页面、审计查询/导出 API 和测试。只消费各业务模块发出的审计事件，不改其核心状态机。

## Acceptance

1. 审计记录不可由普通业务接口编辑或删除。
2. 请求体、响应体、错误和导出均按规则脱敏。
3. 筛选和详情可定位巡检决定、账号/权限和系统参数变更。
4. 旧日志入口被经理版标签页替代，无重复导航。

## Evidence

返回审计事件契约、脱敏/不可变/范围测试、各标签页截图和旧入口清理清单。

## Verification

先运行审计不可变、脱敏、范围、导出和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
