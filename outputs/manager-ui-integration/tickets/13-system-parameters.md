# Ticket 13：系统参数、巡检规则与知识库

## Outcome

授权管理员在经理版“系统参数”中配置 ASR、AI、队列与保留策略，并在同一模块管理巡检规则和知识。

## Blockers

Ticket 01、Ticket 06、Ticket 07、Ticket 11。

## Scope

- ASR 主备、AI URL/模型、队列阈值、保留周期配置。
- 巡检规则与知识库标签页，合并当前独立入口。
- 配置校验、敏感值掩码、变更确认、影响说明和失败回滚。
- 无权限、未配置、外部服务不可用和并发修改状态。

## Ownership

独占系统参数、规则/知识页面、配置 API/schema 增量和测试。不得修改录音或巡检状态机；通过 Ticket 06/07 契约验证配置影响。

## Acceptance

1. 密钥和令牌不回显明文、不进入日志或浏览器持久存储。
2. 配置保存前由服务端校验；并发修改不会静默覆盖。
3. 规则/知识旧入口被目标标签页替代，数据和权限不丢失。
4. 变更产生可供 Ticket 14 展示的审计事件。

## Evidence

返回配置契约、敏感字段策略、校验/并发/权限测试、参数与规则标签页截图。

## Verification

先运行配置校验、并发、权限、secret lint 和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
