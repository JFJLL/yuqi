# Ticket 15：小程序巡检闭环与个人功能

## Outcome

已登录员工可在原生小程序完成首页待办、问题查看、整改反馈、申诉、设备查看和个人资料管理。

## Blockers

Ticket 02、Ticket 04、Ticket 05、Ticket 07、Ticket 08。

## Scope

- 首页与待办、问题列表/详情、证据授权展示。
- 整改反馈、图片/文本证据、修订、确认和状态反馈。
- 申诉提交、进度和结果；本人设备；个人资料和退出。
- 适配经理小程序视觉，同时复用当前更完整闭环 API。
- 弱网、重复提交、登录过期、无数据和无权限处理。

## Ownership

独占小程序首页、问题、整改、申诉、设备、个人页面及小程序端测试。认证基础归 Ticket 02；后端业务状态机只通过前序契约调用。

## Acceptance

1. 员工只能访问本人记录，修改 ID 或路径无法越权。
2. 未经人工复核的问题不出现在员工端。
3. 重复点击和弱网重试不会生成重复整改/申诉。
4. 登录过期能回到认证并在恢复后继续安全操作。

## Evidence

返回页面清单、API 映射、本人隔离/幂等测试、小程序关键流程截图或录屏、已知平台限制。

## Verification

先运行小程序契约、权限、弱网/幂等定向测试，再运行 `rtk pnpm lint`、`rtk pnpm typecheck`、`rtk pnpm test`、`rtk pnpm build` 和项目可用的 `rtk pnpm exec miniprogram-ci` 编译检查；修改后执行 `$code-review`。
