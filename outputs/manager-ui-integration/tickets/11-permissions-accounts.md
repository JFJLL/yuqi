# Ticket 11：账号、角色、权限矩阵与数据范围

## Outcome

超级管理员通过经理版权限页管理角色卡、权限矩阵、管理员账号和集团/区域/门店范围，前后端权限一致。

## Blockers

Ticket 01、Ticket 03。

## Scope

- 角色卡、权限矩阵、管理员账号列表/详情/启停。
- 集团、区域、门店范围配置与有效权限预览。
- 将当前底层权限能力完整表达在经理版 UI 中。
- 防止管理员移除自己最后的关键权限或停用最后一个超级管理员。

## Ownership

独占权限与管理员账号页面、权限 API/schema 增量和测试。组织范围引用 Ticket 03；共享布局/导航归 Ticket 01。

## Acceptance

1. 菜单、按钮、查询和直接 API 请求执行同一权限与数据范围规则。
2. 权限变更有审计，重新登录或令牌刷新后的生效规则明确。
3. 最后超级管理员和自锁场景被安全阻止。
4. 页面与 `11-manager-permissions.png` 的角色卡、矩阵和账号结构一致。

## Evidence

返回权限矩阵定义、范围算法、关键越权/自锁测试、页面截图及供其他模块使用的权限检查契约。

## Verification

先运行权限矩阵、范围、会话刷新、自锁和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
