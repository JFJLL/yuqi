# Ticket 05：统一设备管理

## Outcome

管理员在一个经理版“设备管理”模块内完成设备台账、员工绑定和运行状态管理。

## Blockers

Ticket 01、Ticket 04。

## Scope

- 台账、绑定关系、运行状态三个标签页。
- 新增/导入设备，绑定、调拨、解绑、审批/结果状态及操作历史。
- 合并当前“设备绑定”和“设备运维”能力，移除重复入口但保留数据与流程。
- 处理离线、最后心跳、版本、异常和空状态。

## Ownership

独占设备页面、设备 API/schema 增量和测试。共享导航由 Ticket 01 所有；员工与门店只通过既定契约引用。

## Acceptance

1. 设备序列号/标识唯一，绑定与调拨并发操作原子化。
2. 管理员只能操作范围内门店和员工的设备。
3. 三类信息在经理版页面语言下清晰可见，旧重复导航不再面向用户。
4. 小程序所需的本人设备摘要 API 稳定并有契约测试。

## Evidence

返回状态机、接口契约、并发/越权测试、三个标签页截图和提供给 Ticket 13 的本人设备 API。

## Verification

先运行设备状态机、并发、权限和 UI 定向测试，再运行 `rtk pnpm verify`；修改后执行 `$code-review`。
